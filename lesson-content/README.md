# Материалы уроков

Четыре папки — по одной на каждый вид материала. Имена латиницей:
путь попадает в URL, а кириллица там кодируется в нечитаемый вид
и ломается при переносе между системами.

| Папка | Что внутри | Куда попадает в приложении |
|---|---|---|
| `1-lectures/` | тексты лекций | шаг 1 «Лекция» |
| `2-images/` | картинки и схемы | внутрь лекции |
| `3-warmup-audio/` | записи распевок | шаг 3 «Распевки» |
| `4-song-tracks/` | фрагменты песен на слух | шаг 4 «Упражнение с песней» |

## Как именовать файлы

Номер урока — всегда две цифры, иначе 10-й урок встанет между 1-м и 2-м.

```
3-warmup-audio/L07-01.mp3     урок 7, распевка 1
4-song-tracks/L07-song-1.mp3  урок 7, фрагмент песни 1
2-images/L07-palate.png       урок 7, схема мягкого нёба
```

## Как материал подключается

Файл сам по себе в уроке не появится — на него нужна ссылка в данных урока.

- **Распевка:** в `data/lesson-plans.json` у нужного упражнения добавить
  `"src": "lesson-content/3-warmup-audio/L07-01.mp3"`. Плеер появится сам:
  он включается ровно по наличию `src`.
- **Трек песни:** у урока в `song` должен быть массив `tracks` того же вида,
  что в `data/lesson-01.json` — с `audio`, `title` и разметкой вдохов `lines`.
  Пока `tracks` нет, шаг «Песня» показывает задание и список песен без плеера.
- **Картинка:** блок `{ "type": "image", "src": "...", "caption": "..." }`
  в `lecture.blocks`.

Схемы, которые рисуются разметкой (шкала, таблица, панели), картинок не
требуют — см. типы блоков `scale`, `table`, `panels` в `app.js`.

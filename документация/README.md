# Документация

Юридические документы и страница «О преподавателе» в читаемом виде — те же
тексты, что ученик видит в приложении, в разделе «Ещё».

| Документ | Markdown | PDF |
|---|---|---|
| Публичная оферта — договор возмездного оказания услуг | [оферта.md](оферта.md) | [оферта.pdf](оферта.pdf), 7 стр. |
| Обработка персональных данных по 152-ФЗ | [политика-конфиденциальности.md](политика-конфиденциальности.md) | [политика-конфиденциальности.pdf](политика-конфиденциальности.pdf), 4 стр. |
| Биография и подход к работе | [о-преподавателе.md](о-преподавателе.md) | [о-преподавателе.pdf](о-преподавателе.pdf), 2 стр. |

PDF — формат A4, с нумерацией страниц, годится для печати и отправки. Текст в
них настоящий, а не картинка: по нему работает поиск и копирование.

## Эти файлы не правятся руками

Единственный источник правды — **`../legal.js`** в корне приложения. Именно его
читает приложение, а файлы в этой папке только пересобираются из него.

Если поправить .md напрямую, тексты разойдутся: в приложении у ученика будет
одна редакция оферты, а в этой папке — другая. Для публичной оферты это прямая
юридическая проблема, потому что обязательна та редакция, которая опубликована
в приложении.

Правильный порядок: изменить `../legal.js` → пересобрать → закоммитить оба.

```
cd "путь/до/папки/приложения"
node документация/собрать.js
```

Скрипт выполняет `legal.js` в песочнице, забирает из него объект `LEGAL_DOCS` и
перезаписывает .md и .pdf целиком. Ничего, кроме них, он не трогает.

Как он делает PDF: верстает временный HTML и печатает его через Chrome
(`--headless --print-to-pdf`) — сторонних конвертеров на этой машине нет,
Homebrew не установлен. Номера страниц дописываются вторым проходом через
PyMuPDF из venv `~/.local/vocal-stt`, потому что Chrome из командной строки
свой колонтитул настроить не даёт.

Обе эти части необязательные: **Markdown собирается всегда**. Нет Chrome —
будет только Markdown, скрипт скажет об этом и не упадёт. Нет venv — PDF
соберётся без номеров страниц.

## При смене редакции

Поле `version` у документа в `legal.js` («Редакция от …») — это дата, на
которую ученик соглашается. Меняя условия, обновляйте и её: по п. 13.2 оферты
новая редакция вступает в силу через 7 дней после публикации и не
распространяется на уже оплаченные занятия.

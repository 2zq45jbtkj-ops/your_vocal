# Документация

Юридические документы и страница «О преподавателе» в читаемом виде — те же
тексты, что ученик видит в приложении, в разделе «Ещё».

| Файл | Что это |
|---|---|
| [оферта.md](оферта.md) | Публичная оферта — договор возмездного оказания услуг |
| [политика-конфиденциальности.md](политика-конфиденциальности.md) | Обработка персональных данных по 152-ФЗ |
| [о-преподавателе.md](о-преподавателе.md) | Биография и подход к работе |

## Эти файлы не правятся руками

Единственный источник правды — **`../legal.js`** в корне приложения. Именно его
читает приложение, а файлы в этой папке только пересобираются из него.

Если поправить .md напрямую, тексты разойдутся: в приложении у ученика будет
одна редакция оферты, а в этой папке — другая. Для публичной оферты это прямая
юридическая проблема, потому что обязательна та редакция, которая опубликована
в приложении.

Правильный порядок: изменить `../legal.js` → пересобрать → закоммитить оба.

```
cd "путь/до/папки/приложения"
node документация/собрать.js
```

Скрипт выполняет `legal.js` в песочнице, забирает из него объект `LEGAL_DOCS` и
перезаписывает три .md целиком. Ничего, кроме них, он не трогает.

## При смене редакции

Поле `version` у документа в `legal.js` («Редакция от …») — это дата, на
которую ученик соглашается. Меняя условия, обновляйте и её: по п. 13.2 оферты
новая редакция вступает в силу через 7 дней после публикации и не
распространяется на уже оплаченные занятия.

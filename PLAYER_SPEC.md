# Плеер распевки — единая спецификация (обязательна везде)

Это правило проекта, а не пожелание. Плеер распевки — **один компонент**,
и он выглядит и работает одинаково на каждом экране, где показывается
аудио-упражнение:

- экран урока «Распевки»,
- экран «Избранные распевки»,
- экран «Упражнение с песней» (свой набор функций, но по тому же принципу —
  см. ниже),
- любой новый экран в будущем, где будет показываться распевка.

**Менять player нужно в одном месте.** Если требуется что-то добавить или
поправить в плеере — правки вносятся в общие функции, а не в отдельный экран:

- `warmupCardHtml(ex, extraHtml)` — вся разметка карточки (в `app.js`)
- `wireWarmupCard(ex)` — обработчики аудио-элемента, темпа, тональности
- `wireWarmupControls(onFav)` — обработчики play/seek/шестерёнка/звезда/loop/autoplay
- `warmupSettingsPanelHtml(ex)` — содержимое панели настроек под шестерёнкой

Любой экран, который показывает распевку, обязан использовать эти три-четыре
функции, а не копировать разметку/обработчики заново. Если это правило
нарушено — значит где-то допущена ошибка, это баг, а не альтернативный вариант.

## Что обязательно должно быть в плеере распевки

1. **Перемотка** — только стрелочки назад/вперёд (±10 сек), без числа "10" на иконке.
2. **Play/Pause** — кнопка в центре кольца прогресса.
3. **Кольцо прогресса** вокруг play/pause — визуально отражает позицию воспроизведения.
4. **Звезда «избранное»** — цвет жёлтый (`oklch(84% 0.15 92)`), не терракотовый.
   Обычно — простой toggle. Только на экране «Избранные распевки» звезда
   вместо простого удаления показывает отменяемый тост на 10 секунд
   («Убрано из избранного · Nс» + кнопка «Вернуть») — это единственное
   законное отличие в поведении звезды между экранами.
5. **Шестерёнка настроек** — открывает единую карточку (`.settings-box`) с:
   - **Темп** (слайдер 50–100%, реальный BPM в подписи)
   - **Тональность** (слайдер −5…+3 полутона, шаг 0.5, реальный питч-шифт
     через SoundTouchJS, независимый от темпа)
   - **Повтор (loop)** — переключатель
   - **Автовоспроизведение следующей** — переключатель (общий на все
     упражнения текущего экрана)

Все четыре настройки — в одной карточке с разделителями между строками,
без отдельных теней на каждую (см. фикс от 28.07.2026 — раньше были
отдельные "ячейки", это неправильно).

**Анимация открытия/закрытия панели настроек обязана быть зеркальной.**
Единая точка привязки — верх панели под шапкой плеера, никакого якоря снизу.
Высота контейнера (`grid-template-rows: 0fr → 1fr` у `.settings-panel`),
прозрачность и вертикальное смещение содержимого (`opacity` / `transform:
translateY(...)` у `.settings-box`) анимируются одной и той же
длительностью и одним и тем же easing'ом (сейчас `.25s ease`) — ни у одного
из этих трёх параметров не может быть своего отдельного transition или
мгновенного скачка без transition. Любой постоянный отступ содержимого от
верхней границы (например `margin-top`) должен быть задан безусловно, а
не только в состоянии `.open` — если отступ навешивается только классом
`.open` без собственной анимации, он прыгает мгновенно в момент
переключения класса, и при закрытии контент дёргается раньше, чем
схлопывается высота строки грида (это был реальный баг, пофикшен
05.08.2026 — `padding-top` в `.settings-panel.open .settings-panel-inner`
заменён на безусловный `margin-top` + анимируемые `opacity`/`transform`
на `.settings-box`).

## Технические детали, которые нельзя терять при рефакторинге

- Тональность 0 → обычный `<audio>` (надёжно играет всегда, в т.ч. в
  беззвучном режиме iOS). Тональность ≠ 0 → Web Audio + SoundTouchJS.
  Переключение движка происходит **на лету**, без остановки трека.
- У каждого запуска движка — счётчик поколений (`shiftGeneration` /
  `songShiftGeneration`), который аннулирует все более ранние ещё не
  подключившиеся запуски того же трека. Без этого при быстром движении
  слайдера тональности звук накладывается друг на друга (это был реальный
  баг, пофикшен 28.07.2026 — не убирать эту защиту).
- Пауза/остановка трека обязана инвалидировать поколение (`stopShiftedPlayback(n)`
  с явным `n`), иначе ещё не догрузившийся движок может подключиться уже
  после того, как ученик поставил на паузу.
- Ключи избранного: `favKey(n)` → `"<lessonId>-w-<n>"` для распевок,
  `songFavKey(ti)` → `"<lessonId>-s-<ti>"` для треков песни. Формат менять
  нельзя без обновления парсинга в `renderFavorites()`.
